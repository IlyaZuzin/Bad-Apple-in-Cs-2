# Bad Apple in Cs 2

Этот проект был сделан чисто «по приколу». Если вы собираетесь повторить также (или с другим роликом), то вам следует действовать по инструкции ниже. 

Чтобы всё заработало, вам необходимо изменить пути к вашим файлам во всех скриптах. Не забудьте скачать видео в формате MP4 (необязательно Bad Apple).
Далее запустите скрипт GetFrames — он сохранит в папку каждый кадр видео. Затем запустите CreateCfg — он создаст конфигурационные файлы для игры. Также можно заранее запустить файл GetAudio, чтобы извлечь звук из видео (это необязательно, если у вас уже есть аудио).
Теперь заходите в CS, запускайте карту Mirage с ботами, выбирайте команду террористов и вводите в консоль:
sv_cheats 1; mp_freezetime 0; bot_kick; sv_infinite_ammo 1; mp_restartgame 1
Перед тем как запустить скрипт CS 2, измените переменную frame_max на количество ваших конфигов (Важно: я не смог реализовать «стоп-кран», поэтому, пожалуйста, сделайте его на всякий случай).
Нажмите на клавиатуре клавишу «минус» (-) с закрытой консолью и ждите — это может занять много времени, пока скрипт не завершится.
После всех манипуляций запускайте CreateVideo. Готово!
